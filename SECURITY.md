# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `si-scars`, please report it responsibly:

1. **Do not** open a public issue or discuss the vulnerability publicly.
2. Report security concerns via GitHub Private Vulnerability Reporting on the repository (Security tab -> Advisory -> Report a vulnerability).
3. If GitHub Private Vulnerability Reporting is unavailable, contact the repository maintainers directly with reproduction details.

Please provide:
- A clear description of the vulnerability.
- Steps or a minimal proof of concept to reproduce the issue.
- Potential impact and any suggested mitigations.

Maintainers will acknowledge receipt within 48 hours and coordinate a coordinated disclosure timeline.
